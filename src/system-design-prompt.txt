## 论文题目
中文：智能教学系统的设计与实现
英文：Design and Implementation of Intelligent Teaching System

## 背景
随着大模型的应用浪潮兴起，大模型已经渗透到各个领域。现在市场上缺乏一个与大模型深入融合的教学系统以让AI更好地驱动教育发展。
本系统旨在设计实现一个基于大模型的功能齐全的WEB教学系统，目标群体是中小学学校。

## 系统需求分析
# 1. 概述
系统需要能够满足班级教学系统的基本能力要求。
- 需要提供登录鉴权功能。区分教师、学生和管理员角色，各个角色看到的视图和数据不同。学生和教师根据班级进行组织和数据隔离。
- 能够做到优美的UI界面吸引学生的注意力、提供简洁易于理解的操作。
- 教师可以发布课件、视频等，学生可以进行预览下载；教师可以发布作业、批改作业，学生可以提交作业，并且教师和学生可以在作业下面的讨论区讨论。
- 大模型几乎贯穿系统的所有数据模块，系统定位用户（并区分用户角色）所在页面位置将页面数据和用户问题发送给大模型，大模型提供流式回答和Agent能力。

## 系统架构
# 1. 技术选型
本系统采用前后端分离的WEB架构。
前端选用基于JavaScript语言的React框架、后端选用基于Java语言的Spring Boot框架。
前端使用Axios和SockJS库、基于HTTP和WebSocket与后端通信。
关系型数据库使用MySQL 8.0来持久化存储数据、非关系型数据库采用Redis来缓存热点数据。
大模型能力采用openai-java库来调用deepseek、qwen等模型。
Nacos作为动态数据配置中心，大模型的配置和Prompt动态修改核心地。

# 2. 模块划分
（1）登录鉴权模块
系统提供账号密码方式登录页面，后端返回JWT授权用户权限。后端数据库存储用户角色，并根据用户角色展示不同的视图。
后端对数据做好保护工作。

（2）用户组织模块
学神和教师都需要属于一个班级。同一个班级内的数据共享并和其他班级进行隔离。管理员可以查看所有班级的数据资源。
班级内的教师对其他模块基本拥有读写权限，而学生基本仅拥有读权限。并且教师可以在班级内添加、删除成员。
大模型会读取班级成员进行分析回答用户针对所在班级的问题。

（3）主页模块
主页依靠前端tsParticles和GSAP渲染出绚丽的星空质子路线图，路线图数据从Nacos中动态获取，点击页框可进入该课的仓库。
大模型会读取主页路线图数据分析回答用户针对系统、课程安排的问题。

（4）课程仓库模块
以班级为单位，教师可以创建目录、上传各种文件（支持分片上传、文件哈希去重、多文件上传、断点续传。
并且我设计了一个文件存储服务，因为价格和目前实际情况考量而没有使用OSS服务），形成一个类Unix的虚拟文件系统。
每一项有复制路径、预览（针对可预览文件）、修改名称、删除、查看属性等操作（学生无写操作）。
课程仓库还支持搜索文件，后端使用广度优先搜索，每搜索到一个文件使用WebSocket发送给前端显示。并且可以通过导航栏或者前端提供的导航输入框来导航到某一个目录。
与日常使用的Windows系统非常相似，易于操作。
大模型可以读取相关文件、或者课程结构数据回答用户针对文件或课程数据的问题。

（5）作业区模块
以班级为单位，教师可以发布作业（作业包括标题、描述、附件，类似于邮件系统），学生可以提交作业。
作业有一个状态机，包括已提交、被退回、作业有更新、重新提交。教师可以打回作业以让学生重新提交，前端显示作业状态以让用户区分。
教师可以查看所有作业以及某个作业的所有学生提交，修改和删除作业。
学生可以查看所有的作业，并且可以查看自己的所有提交。
大模型可以读取作业描述和附件分析回答问题、也可以读取学生提交情况进行分析回答问题等等。

（6）讨论区模块
讨论区用于作业区等模块。在某个作业下班级所有人可以发起讨论，所有人可以讨论，是一个典型的讨论区形式。
大模型可以读取讨论区聊天记录来总结内容，并回答用户问题等。

（7）大模型模块
系统整体提供"Ask For AI"机器人。可以全方面回答用户（学生、教师、管理员）问题，更好地辅助教育。
并在各个模块有系统数据的帮助以更好地回答用户问题。另外还有Agent功能的添加，可以导航到相关页面、定时发送邮件提醒作业等等功能。
